# VoidedX

VoidedX includes a browser-based Lua/Luau obfuscator in Vault Protection. Script source is processed locally in the browser and is not sent to an obfuscation server.

The obfuscator is based on Prometheus by Elias Oelschner:

**Based on Prometheus by Elias Oelschner, https://github.com/prometheus-lua/Prometheus**

The original Prometheus license is included at `obfuscator/LICENSE-PROMETHEUS.txt`.
