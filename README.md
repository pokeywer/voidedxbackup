# VoidedX

VoidedX is a static website with Vercel serverless API routes. Deploy the repository root with the project's existing Firebase and Vercel configuration.

Vault Protection offers Auto, Low, Medium, and High obfuscation strengths in LuaU mode. Auto selects High up to 10,000 UTF-8 bytes and Medium above that; owners can override the selection. Every strength splits string literals using native concatenation, while High also uses Prometheus's stronger numeric representation pass. By default the LuaU compatibility profile skips Prometheus's VM, debug-heavy AntiTamper, string-encryption, and constant-array passes because they can break Roblox scripts. New vaults have a mild watermark tamper check enabled by default; it stops execution if its marker is changed without adding debug hooks or infinite loops, and owners can turn it off. A separate optional VM setting adds one Prometheus VM pass; it is experimental for Luau and may break unsupported syntax, so it is off by default. New vaults store readable source as plain text in Firestore so owners can review it; this is not encryption. Older gzip-base64 source records remain supported. The obfuscated execution copy is still gzip-base64 encoded in storage and decompressed by the API for delivery. Unkeyed raw loaders fetch the generated body directly instead of embedding a second copy inside the loader. The input limit is 2 MiB, but the estimated Firestore vault document remains capped at about 870 KiB, so plain source reaches the document limit sooner than compressed source. Re-saving unchanged source at the same strength and protection settings reuses the last generated copy in that browser session. Obfuscation adds friction, but code delivered to a client can still be captured and analyzed at runtime.

Prometheus describes its LuaU support as basic and unfinished, so this profile may still not support every Luau-specific syntax or Roblox script pattern. Keep a backup and try generated code in a private test place before using it broadly.

Based on Prometheus by Elias Oelschner, https://github.com/prometheus-lua/Prometheus
