# VoidedX

VoidedX is a static website with Vercel serverless API routes. Deploy the repository root with the project's existing Firebase and Vercel configuration.

Vault Protection offers Auto, Low, Medium, and High obfuscation strengths in LuaU mode. Auto selects Medium up to 10,000 UTF-8 bytes and Low above that; owners can override the selection. High uses Prometheus's Strong preset with the existing LuaU compatibility filter, so the VM, anti-tamper, string-encryption, and constant-array steps remain disabled. The source stays readable in `code`; the generated copy is stored separately and served by the existing raw, verify, and payload routes. The browser compresses the generated copy before storing it, while the API decompresses it for execution. Unkeyed raw loaders now fetch the code body directly instead of embedding a second copy inside the loader, keeping the bootstrap small for large scripts. Obfuscation accepts source files up to 700 KiB, and the estimated Firestore vault document is capped at about 870 KiB so both copies fit safely. Re-saving unchanged source at the same strength reuses the last generated copy in that browser session.

Prometheus describes its LuaU support as basic and unfinished, so this profile may still not support every Luau-specific syntax or Roblox script pattern. Keep a backup and try the output in a private test place before using it broadly.
