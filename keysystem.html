Beginner guide — set up your key system
  1. Turn it on. Switch on Enable Key System to show the key settings.
  2. Choose who gets keys. Add a Private Key for people you choose, or enable Public Key so visitors can request one from your Get-Key page.
  3. Set the timer. Choose how long a key lasts and how many players may use it. Expired keys are rejected; the remaining time is shown in the in-game status badge.
  4. Set up the in-game popup. Turn on In-Game Key GUI to ask players for a key in Roblox. Customize the title, colors, and button, then use the live-preview controls to replay the entrance, unlock, Get-Key, and close/open animations. After a key verifies, VoidedX saves it locally when the executor supports file saving, and checks it automatically next run.
  5. Optional Linkvertise. In the Get-Key Link tab, copy the Get-Key URL. Make that the destination of a Linkvertise Target Link with Anti-Bypass enabled. Save your Linkvertise token, paste the Linkvertise share URL into Ad-Gate Link, then Apply Changes.
  6. Save your settings. Click Apply Changes after editing. Share the Get-Key URL with players who need a public key.

Saved keys stay in the player's executor files on that device. The server still checks each key and expiration. Expiration blocks future runs; it cannot stop a script that is already running.
