VOIDEDX PROMETHEUS LOW / MEDIUM PATCH

This integrates the Prometheus engine into VoidedX's existing Vault Protection panel. It does not include the separate Prometheus website interface.

Upload files into the matching repository paths and replace files when GitHub asks. Keep all five files in prometheus-engine/assets/ together.

The strength selector offers Auto, Low, and Medium in LuaU mode. Auto uses Medium for scripts up to 10,000 characters and Low for longer scripts; users can choose either strength manually. To keep Roblox service names and other string literals intact, the compatibility profile skips Vmify, AntiTamper, EncryptStrings, and ConstantArray. When enabled, saving a vault runs the supplied Prometheus engine in the browser and stores its generated output separately from the original source. Existing /api/raw, /api/verify, and /api/payload routes deliver the transformed copy. This patch adds no API endpoints. Do not replace the entire api folder; only copy the listed API files.

Prometheus documents LuaU support as basic and unfinished; some Luau-specific syntax or Roblox script patterns may still be unsupported. Keep a backup and try the output in a private test place before broad use.
