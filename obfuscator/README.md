# VoidedX Lua Obfuscator

This browser bundle provides the Lua/Luau obfuscator embedded in the VoidedX vault editor. It is based on Prometheus by Elias Oelschner:

**Based on Prometheus by Elias Oelschner, https://github.com/prometheus-lua/Prometheus**

The engine runs in the browser. Keep the files in `assets/` together with this page; the worker and WebAssembly files are required. The original license is in `LICENSE-PROMETHEUS.txt`.
